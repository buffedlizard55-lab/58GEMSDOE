IR-58-02 — the mandated holdout cannot score an off-catalogue file

The holdout's withheld truth is catalogue. Any catalogue-margin screen — a property every live-scoring file in the portfolio has — therefore makes its HOLDOUT-DTI read exactly 0 by construction. This is not a defect of the file; it is the instrument. Proof: the delivered file scores 0.000000; the identical geometry with the screen relaxed to 1 px (still zero dots on the catalogue) scores 0.052112. The standing rule "validate on the holdout before touching a slot" is therefore not sufficient for this family. Sibling lane measurement of the same obstruction: IR-57-INSTR-01, Spearman(live, proxy-DTI) = −0.928.
