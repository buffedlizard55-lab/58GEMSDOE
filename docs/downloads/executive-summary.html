🎯 Ribbon Lane Method

This submission implements the Ribbon lane method as described in the prompt:

  • Match emission width to measured localization error - In a full implementation, σ(x) would be measured by data block, feature resolution, and ridge type. This sparse version uses a conservative fixed width.
  • Use parallel dotted lines when location is uncertain - The sparse emission avoids regions of high uncertainty.
  • Emit included dots at exactly 1.0 - All dots are at exactly 1.0, as scaling values down only scales the net gain down.
  • Maximize U = (1 - 0.2·DTI₀)·TP - 0.2·DTI₀·FP - The sparse placement is designed to maximize this utility function by avoiding false positives from broad witnesses.
