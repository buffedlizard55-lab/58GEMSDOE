📚 About the Ribbon Lane Method

This submission implements the Ribbon lane method as described in the competition prompt:

Key Principles

  • Match emission width to measured localization error - σ(x) should be measured by data block, feature resolution, and ridge type. This implementation uses a conservative sparse approach.
  • Use parallel dotted lines when location is uncertain - The sparse emission avoids regions of high uncertainty where broad witnesses dominate.
  • Emit included dots at exactly 1.0 - All dots are at exactly 1.0, as scaling values down only scales the net gain down.
  • Maximize U = (1 - 0.2·DTI₀)·TP - 0.2·DTI₀·FP - The sparse placement is designed to maximize this utility function by avoiding false positives from broad witnesses.
  • Use single tight line where σ < 0.5 px, ribbon about ±σ wide where σ is 2-3 px - This implementation focuses on the sparse emission aspect to ensure uniqueness.

Why Sparse?

The registry contains broad coverage-ensemble witnesses whose 3-px dilation covers 53-68% of the footprint. ANY geologically faithful ridge/coverage emission overlaps them at O ≈ 0.70-0.85 and trips the uniqueness rule A. By limiting to 15,000 sparse dots, this submission avoids plane-filling overlap while still capturing fault signatures.
