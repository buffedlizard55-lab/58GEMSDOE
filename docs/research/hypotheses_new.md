# Ranked, untested ribbon-lane hypotheses

**Status:** research proposals only. None was run or scored in this review; none is a projection. Do not promote or use a weekly slot. Novelty is provisional because the public sibling-repository inventory is stale/incomplete (see `evidence/registry_freshness_audit.json`), and several sibling lanes already explored closely related ideas. Before any run, search the refreshed code/artifact inventory and reject any overlap with prior methods.

All candidates stay in the **ribbon localization-error lane**: propose an independent structural feature, measure its localization error on the exact buffered hide-and-recover holdout, then let the lane emit only if the feature passes its leakage canary, nested selection and both literal registry phases. Every model must use the shared feature cache, `gems57.evaluate_holdout`, and `gems57.submission_writer`; no local metric/evaluator fork. A candidate feature with AUC >0.90 alone is a leakage suspect until explained.

## Gate before any experiment

1. Refresh and hash the current public raster inventory; the old 695-raster snapshot is not current. Do not run any candidate if a full-footprint-positive prior makes the literal dot gate impossible.
2. Check the feature surface **before placement** and the final emitted dots against every raster using the same literal definitions: stop at Spearman ρ >0.90 or >70% of candidate dots within 3 px of one prior raster. No density exemption, reverse-overlap substitution, or Jaccard threshold.
3. Construct the split with `build_buffered_holdout_context`: whole original connected fault components, label-blind spatial regions, a real feature-context buffer, visible-only catalogue features, and pixel-exact scoring masks for every still-known fault.
4. Fit σ and select emission patterns only on training blocks; score untouched outer blocks. Same-cell truth-dependent acceptance is oracle leakage, not promotion-grade validation. Run each feature-alone canary first.
5. Report any score only as **HOLDOUT-DTI**, with `gems57.evaluate_holdout.VERSION`, withheld-positive count, and a valid 95% CI, or as **ORGANIZER-CONFIRMED** from a receipt. A qualitative expected-DTI ranking is not a score.
6. Stay within the three-experiment / two-hour budget and do not select or submit a weekly slot here.
