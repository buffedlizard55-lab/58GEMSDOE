Candidate geological hypotheses

Five candidates were written down before any of them was run, ranked by expected DTI improvement and implementation cost. Each names the layer(s) involved, the physical signature, why it should catch a fault the USGS/INGENIOUS catalogue does not contain, and how it differs from anything already implemented in this repo or in the sibling lanes whose hypothesis lists were read (57GEMSDOE/BRIEF.md, GEMSDOE32/docs/research/*.md: H33-A…E, H34, H57-1…5, H57-G1…G5, H61-1…5, H62-1…5).

Rank 1 — H58-R: emissive-width calibration of multi-family ridge detections (IMPLEMENTED)

layer(s)all 19 organizer bands, grouped into the organizer's own six families (magnetic, gravity, topographic, subsurface, geodetic, seismic) at three ridge scales (1.5 / 3.0 / 6.0 px = 150 / 300 / 600 m)
physical signatureHessian ridge magnitude | |λ₁| − |λ₂| | = 2·min(|tr|/2, disc), i.e. curvature across strike exceeding curvature along strike — the definition of curvilinear structure. Not an edge detector: an edge has equal eigenvalue magnitudes and scores zero here.
why off-cataloguedetection uses no catalogue information by construction (guarded by tests/test_holdout.py::test_no_catalogue_derived_feature_feeds_the_holdout), so it can only surface lineaments the catalogue does not already contain; and dots on the catalogue are masked by the organizer, hence worthless.
differencesibling H34 blurred a belief field and re-ran a max-coverage emitter — a field transform. This lane transforms the emission support geometry: parallel dotted lines at the kernel radius, chosen per segment from a measured σ. Sibling H33-A ("multi- physics orientation") used band orientation products; this lane never combines channels into one index, it detects per channel and per scale and keeps the winning stratum's identity.
costimplemented: 3 registry scripts, one cached field, ~20 min per sweep
resultHOLDOUT-DTI (gems58.metric/v1, 60,359 withheld positives): width 1 = 0.039363, width 5 = 0.040008 at an identical 38,000-dot budget. σ_detect = 1.70 px (per-component σ median 6.88 px) ⇒ the lane's rule selects the ribbon, and the per-segment plan resolves it to 5 lines at 0, ±300 m, ±600 m. Delivered file is this arm.

Rank 2 — H58-S: flight-line artefact suppression before detection (NOT RUN, highest value)

layer(s)tmi, rtp, tmi_hg, tmi_vg, tc
physical signatureaeromagnetic levelling residuals appear as lineaments parallel to the survey flight lines, at a spacing set by the survey, not by geology. Fitting and removing that directional comb leaves tectonic response.
why off-catalogueit removes false ridges, so it raises the precision of every off-catalogue detection without touching the catalogue.
differencesibling H61-5 works scarp morphology from the 1 m DEM; sibling H57-U proposed "flight-line-aligned magnetic mimic suppression" as an untested backlog item and never ran it. This is that idea with a concrete estimator.
costhigh-ish: needs the survey line geometry (public USGS GeoDAWN metadata)
statusnot validated — cannot be claimed. Named here because it is the largest single reduction in false support available to this lane.

Rank 3 — H58-T: directional (tensor) σ instead of scalar σ (NOT RUN)

layer(s)same field as H58-R
physical signaturethe residual between a detected ridge and the true trace is anisotropic: along-strike the detection is far better than across-strike, because the ridge is continuous and the offset is a single number.
why off-catalogueit does not change which lineaments are found, only how wide their emission is, so it is orthogonal to the catalogue.
differenceH58-R uses the RMS (isotropic) σ because the kernel is isotropic; the tensor version measures the error in the ridge frame and picks the offset direction per segment. It is a strict generalisation and therefore cannot lose except through extra parameters.
costmedium: same machinery, two more columns in the σ table
statusnot validated

Rank 4 — H58-U: held-out-inventory truth set (NOT RUN, unblocks the instrument)

layer(s)none (a data-acquisition hypothesis)
physical signature—
why off-catalogueit builds a holdout whose truth is not the catalogue: a state or regional geological compilation (e.g. the SGMC-derived rasters the sibling lane already pins in 57GEMSDOE/data/external/) that the organizer's catalogue also excludes. Only then can a hide-and-recover score rank off-catalogue placements.
differenceevery sibling lane's instrument uses the catalogue as truth; this is the first that does not.
costmedium; the source is already mirrored inside the sibling repository, so no new binary fetch is required
statusnot run — the deliverable in this session is honest about the instrument limit instead (IR-58-02)

Rank 5 — H58-V: seismic-catalogue declustering conditioning (NOT RUN)

layer(s)deq_n100a15, ieq_n100a15
physical signatureearthquake density as a weak prior on where structure exists, after removing the network-detection footprint (which follows roads, basins and population, not faults).
why off-cataloguea declustered epicentral lineation is evidence of a structure that a surface catalogue may not have mapped.
differencesibling H61-2 / H33-E used seismicity lineations directly; this conditions on the detection footprint first.
costlow
statusnot run — ranked last because the two seismic bands are 100 km-radius smooth fields and carry almost no resolvable lineation at 100 m

Ranking rationale and the budget actually spent

Rank 1 was implemented because it is the lane, it is cheap, and it is the only candidate whose decision variable (emission width) is measurable on the mandated holdout without new data. Ranks 2 and 3 are the two cheapest real improvements and neither was validated inside the 3-experiment / 2-hour budget; they are named as next work, not as claims. Ranks 4 and 5 need either a new truth set or carry too little signal per hour.
