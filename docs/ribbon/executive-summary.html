Why the portal rejected an earlier file: "Predicted values must be in range [0, 1]"

That message means a value outside [0, 1] — most often NaN — landed inside the scored footprint. NaN is legal and expected outside the footprint (the organizer's own example submission does exactly that), but it is rejected inside it.

Every competition number on this site is labelled: ORGANIZER-CONFIRMED (the submission page returned it for a named file hash — none in this repository yet), OWNER-REPORTED (quoted from the brief or the owner's pages: 0.2778, 0.3195, 0.3774), or HOLDOUT-DTI (measured here with the exact metric on gems58-pooled-hide-v1). A projection is never presented as a score.
