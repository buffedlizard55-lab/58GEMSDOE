One lane of a parallel run on the DOE GEMS Prize. The lane is fixed by the standing prompt: match the emission width to the measured localisation error. Full submit guide →

Why the group's best file scores what it scores

With R = 300 m = 3 px, α = 0.2, β = 0.8 and FN = |G| − TP, the official index collapses to

DTI = TP / (0.2·(TP + FP) + 0.8·|G|)

so every emitted pixel of unit mass moves the denominator by exactly 0.2 and the numerator by its kernel credit. One dot pays if and only if its credit exceeds 0.2 · DTI₀. At the leader 0.3195 (OWNER-REPORTED) that is 0.0639 — within 281 m of a scored truth pixel. The metric is a distance filter, not a precision filter. That is why the top file is binary, sparse and off-catalogue, and why dense parallel chains that hug the catalogue spend mass for nothing. Machine-checked in Research.

Honest gap

Detection is 13.6% of the withheld catalogue target. A file that reaches 0.3195 needs weighted coverage of roughly 45 % of the hidden faults. The binding constraint is coverage, not emission geometry. No emission rule in this lane closes that gap, and this repository does not claim it does.
