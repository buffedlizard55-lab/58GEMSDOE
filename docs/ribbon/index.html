What changed in this session

The emission rule

Every earlier file in this family places dots on the detected surface. The judge's kernel is a 3-px triangle, and the hidden truth is scattered around the true structure, so the expected credit of a dot is the kernel applied to the blurred density. This session's candidate covers that scatter density and places each dot only while its marginal expected credit exceeds the metric's own inclusion bar α·DTI₀ — the metric's first-order condition, not a hand-tuned width. The number of parallel dotted lines is what the residual test leaves: a single tight line on a sharp ridge, a ribbon where the density is wide.
