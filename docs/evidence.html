How to re-derive any number on the site

  1. pip install --break-system-packages -r requirements.txt (adds scikit-learn for the canary's roc_auc_score).
  2. bash scripts/fetch_feature_stack.sh — 419 MB, sha256-pinned 4371c82e…3bc5; then export GEMS_FEATURE_STACK=~/.cache/gems/training_features.tif.
  3. python3 scripts/fetch_registry_sparse.py and python3 scripts/registry_delta_inventory.py --clones /tmp/reg — the 703 witness rasters.
  4. PYTHONPATH=src python3 scripts/ribbon_run_adaptive.py — EXP-1 and EXP-2 (~4 minutes).
  5. PYTHONPATH=src:scripts python3 scripts/ribbon_emit_adaptive.py — EXP-3: emit, validate, screen, write the receipts (~2 minutes).
  6. PYTHONPATH=src python3 scripts/check_uniqueness_registry.py <candidate> --workers 2 --out ribbon/uniqueness_full_inventory.json — gate G3 (~30–40 minutes on 2 CPUs).
  7. PYTHONPATH=src:. python3 -m pytest tests -q then python3 scripts/build_site.py (exit 0 = the banner says OK, exit 2 = it does not).
